# Bank Marketing SQL Case Study

## Project Overview
This project contains SQL queries and analysis performed on the Bank Marketing Dataset.

## Tools Used
- MySQL
- SQL

## Dataset
Bank Marketing Dataset (CSV format)

## Analysis Performed
- Customer subscription analysis
- Job-wise subscription count
- Age group analysis
- Campaign performance analysis
- Previous campaign impact
- Loan and housing analysis

## Objective
To analyze customer data and identify factors affecting term deposit subscription.
